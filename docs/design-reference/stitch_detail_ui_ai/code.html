GIÁO TRÌNH MẠNG MÁY TÍNH NÂNG CAO TRANG 14

CHƯƠNG 3: NGUYÊN LÝ HOẠT ĐỘNG VÀ THIẾT LẬP VÙNG (AREA) TRONG OSPF

3.1. Phân chia khu vực (Area Design) và Backbone Area 0:

Giao thức OSPF (Open Shortest Path First) là giao thức định tuyến trạng thái liên kết (Link-State). Để giảm thiểu kích thước cơ sở dữ liệu Link-State Database (LSDB) và tần suất tính toán thuật toán Dijkstra (SPF), OSPF bắt buộc cấu trúc phân cấp mạng thành các vùng (Area).

Backbone Area (Area 0 hoặc 0.0.0.0) đóng vai trò là xương sống trung tâm kết nối tất cả các Area thông thường khác. Mọi lưu lượng định tuyến liên vùng (Inter-area traffic) đều phải đi qua Area 0 nhằm ngăn chặn định tuyến vòng lặp (routing loops).

3.2. Vai trò của ABR (Area Border Router):

Router nằm ở ranh giới giữa một hoặc nhiều Area với Area 0 được gọi là ABR. ABR chịu trách nhiệm tóm tắt và chuyển tiếp LSA Loại 3 (Summary LSA) giữa các vùng.

Hình 3.1: Mô hình phân cấp Backbone Area 0 và Router ABR

LSA Type 3 được tạo lập bởi ABR để truyền dữ liệu định tuyến giữa Area 0 và Area 1.

Dựa trên nội dung tài liệu, có 2 lý do chính và vai trò cụ thể như sau:

1. Ngăn ngừa routing loops: Mọi lưu lượng liên vùng (Inter-area) bắt buộc phải truyền qua Backbone Area 0 để đảm bảo cấu trúc hình sao không sinh vòng lặp.

2. Vai trò ABR: Là Router đứng giữa Area 0 và các Area phụ trợ, có nhiệm vụ tổng hợp và phân phối LSA Type 3 giữa các vùng.
